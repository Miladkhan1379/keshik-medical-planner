# کشیک‌یار | KeshikYar

کشیک‌یار یک نرم‌افزار فارسی و آفلاین برای چیدمان و تحلیل کشیک کادر درمان است.

## امکانات اصلی

- حالت ساده و پیشرفته
- ورود اسامی به‌صورت دستی یا از Excel
- تحلیل برنامه کشیک آماده از Excel با تعیین معنی ستون‌ها
- تعیین تعداد کشیک و تعداد کشیک تعطیل برای هر فرد
- روزهای ممنوع و روزهای ترجیحی
- جفت شدن و جفت نشدن افراد
- اولویت‌بندی قوانین از ۰ تا ۱۰۰؛ مقدار ۱۰۰ یعنی خط قرمز
- تعیین بازه حضور هر فرد
- تعیین بازه زمانی دلخواه حتی بین دو ماه
- تعریف بخش‌های مختلف و ظرفیت متفاوت در روزهای مختلف
- نفر اصلی و کاور
- تنظیم احتمال مورنینگ بر اساس بخش، روز هفته و روز خاص
- قفل کردن کشیک‌های مشخص
- ویرایش دستی همراه با بررسی خطاها
- توضیح علت خالی ماندن جایگاه‌ها
- تحلیل تعداد کشیک، تعطیل، مورنینگ، کاور و نقض قوانین
- خروجی Excel
- پشتیبان‌گیری و بازیابی اطلاعات
- ابزار مستقل «قرعه رندم» در بخش اکسترا
- اجرای آفلاین برای چیدمان و تحلیل

## حالت ساده

برای استفاده سریع طراحی شده و فقط امکانات اصلی مثل اسامی، روزهای ممنوع، جفت شدن، جفت نشدن و بازه چیدمان را نمایش می‌دهد.

## حالت پیشرفته

امکانات تکمیلی مانند چند بخش، ظرفیت روزانه، کاور، مورنینگ، اولویت قوانین، سابقه دوره‌های قبل، بازه حضور افراد و تنظیمات جزئی‌تر را در اختیار کاربر قرار می‌دهد.

## اولویت قوانین

- ۰: بدون اهمیت
- ۲۵: اهمیت کم
- ۵۰: اهمیت متوسط
- ۷۵: اهمیت زیاد
- ۱۰۰: خط قرمز و غیرقابل نقض

ابتدا می‌توان وزن‌های کلی را برای همه افراد تعیین کرد و سپس افراد استثنا را جداگانه شخصی‌سازی کرد.

## اجرای ویندوز

فایل‌های برنامه را در یک پوشه نگه دارید و `START_KESHIK.bat` را اجرا کنید. برای بهترین سازگاری از Chrome یا Edge استفاده کنید.

## نسخه موبایل

نسخه موبایل از همان هسته و همان الگوریتم نسخه دسکتاپ استفاده می‌کند. رابط برای نمایشگر کوچک و لمس بهینه شده و فایل‌های اصلی برنامه داخل بسته موبایل قرار می‌گیرند.

## حریم داده

چیدمان و تحلیل روی دستگاه کاربر انجام می‌شود. اطلاعات اسامی و تنظیمات برای محاسبات اصلی به سرور خارجی ارسال نمی‌شوند. دریافت آنلاین اطلاعات تقویم، در صورت استفاده، به اینترنت نیاز دارد.
