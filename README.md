# کشیک‌یار — KeshikYar 1.1

کشیک‌یار یک برنامه فارسی و آفلاین برای چیدن و تحلیل کشیک است. سورس برنامه مستقیم داخل همین مخزن قرار دارد و Build یا فایل کامپایل‌شده جدا لازم ندارد.

## دو حالت استفاده

- **ساده:** اسامی، روزهای ممنوع، جفت، جفت‌نشدن، بازه تاریخ و تعداد نفرات روزانه.
- **پیشرفته:** بخش‌های مختلف، نفر اصلی و کاور، مورنینگ، تعطیلات، تعداد متفاوت هر روز، سابقه ماه‌های قبل و اولویت قوانین.

## امکانات نسخه 1.1

- ورود اسامی از Excel و انتخاب معنی هر ستون
- تحلیل یک Excel کشیک که از قبل چیده شده
- بازه دلخواه تاریخ، حتی از یک ماه شمسی تا ماه بعد
- بازه حضور جدا برای هر فرد
- بازه فعالیت جدا برای هر بخش
- نفر اصلی و کاور
- ظرفیت متفاوت بخش‌ها در روزهای مختلف
- مورنینگ پیش‌فرض بخش + قانون روز هفته + استثنای یک تاریخ مشخص
- روزهای ممنوع و ترجیحی
- جفت و جفت‌نشدن افراد
- اولویت قوانین از 0 تا 100؛ مقدار 100 یعنی خط قرمز
- چیدمان و تحلیل آفلاین
- خروجی Excel
- ویرایش دستی اختیاری با هشدار
- قفل اختیاری یک خانه و چیدمان دوباره بقیه جدول دور آن
- توضیح اختیاری علت خالی ماندن یک خانه
- پشتیبان‌گیری محلی
- آماده استفاده به شکل PWA روی موبایل

## فایل‌های اصلی سورس

- `index.html` — ساختار رابط برنامه
- `styles.css` — ظاهر برنامه
- `app.js` — منطق رابط، Excel، تقویم و گزارش
- `v11-extra.js` — امکانات تکمیلی نسخه 1.1
- `solver.js` — موتور چیدمان و بررسی قوانین
- `jalali.js` — محاسبات تقویم شمسی
- `holidays.js` — تعطیلات داخلی نمونه
- `xlsx-lite.js` — خواندن و ساخت Excel به شکل آفلاین
- `manifest.webmanifest` و `service-worker.js` — نصب‌پذیری و کار آفلاین نسخه وب/PWA

این‌ها خودِ کد برنامه هستند؛ بنابراین برای GitHub فایل‌های داخل پوشه را آپلود کنید، نه فقط ZIP.

## اجرا در ویندوز

1. فایل‌ها را Extract کنید.
2. `START_KESHIK.bat` را اجرا کنید.
3. برنامه با Chrome یا Edge باز می‌شود.

## استفاده روی موبایل

اگر پروژه روی HTTPS، برای مثال GitHub Pages، منتشر شود مرورگرهای پشتیبانی‌شده می‌توانند آن را مثل یک Web App نصب کنند. بعد از بارگذاری اولیه، فایل‌های اصلی برنامه توسط Service Worker کش می‌شوند تا بخش اصلی برنامه آفلاین هم در دسترس باشد.

## فایل‌های نمونه

- `sample_people.xlsx` — نمونه ورود اسامی و محدودیت‌ها
- `sample_schedule.xlsx` — نمونه جدول کشیک برای بخش «تحلیل Excel آماده»

## Android و iOS
نسخه 1.1 برای موبایل هم آماده شده است. ساده‌ترین روش استفاده PWA از طریق GitHub Pages است. برای بسته Native نیز تنظیمات Capacitor داخل مخزن قرار دارد.

- Android: PWA یا ساخت APK/AAB با Capacitor و Android Studio
- iOS: PWA یا ساخت Native با Capacitor و Xcode
- راهنمای کامل: `MOBILE_FA.md`
- Workflow آماده Android: `.github/workflows/android-apk.yml`
- Workflow تست iOS Simulator: `.github/workflows/ios-simulator.yml`

هسته چیدمان بین Windows، Web، Android و iOS مشترک است و جداگانه بازنویسی نشده است.
