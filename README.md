# کشیک‌یار پزشکی | Keshik Planner

نرم‌افزار آفلاین برای **چیدمان، کنترل و تحلیل کشیک کادر درمان** با رابط فارسی و خروجی Excel.

**ایده و توسعه: میلاد شکاری 98**

> هدف کشیک‌یار این است که برنامه‌ریزی کشیک از یک کار دستی و پراشتباه به یک فرآیند قابل تنظیم، قابل تحلیل و قابل تکرار تبدیل شود.

## قابلیت‌های اصلی

- اجرای آفلاین روی کامپیوتر؛ Solver برای چیدمان به اینترنت نیاز ندارد.
- ورود اسامی و تنظیمات از فایل Excel با Mapping ستون‌ها.
- تعیین تعداد کشیک و تعداد کشیک تعطیل برای هر فرد.
- قانون ۴۸ی و جلوگیری از تکرار یک فرد در یک روز.
- روزهای ممنوع و روزهای ترجیحی.
- تعریف «جفت با» و «نباشد با» برای افراد.
- **سیستم اولویت یکپارچه ۰ تا ۱۰۰** برای قوانین:
  - ۰ = نادیده
  - ۲۵ = کم
  - ۵۰ = متوسط
  - ۷۵ = زیاد
  - ۱۰۰ = خط قرمز / Hard
- تنظیم اولویت‌های کلی برای کل گروه و امکان Override برای هر فرد.
- احتمال مورنینگ در سطح بخش و در سطح روز تقویم.
- درنظرگرفتن مورنینگ دوره‌های قبل برای عدالت بیشتر.
- ظرفیت پیش‌فرض برای هر بخش و ظرفیت متفاوت در روزهای خاص.
- تقویم شمسی، تعطیلات دستی و دریافت اینترنتی تعطیلات در صورت دسترسی.
- سابقه کشیک و کشیک تعطیل ماه‌های قبل.
- تحلیل خطاها، عدالت و جریمه الگوریتم.
- خروجی Excel از برنامه کشیک و گزارش تحلیلی.
- Backup و Restore داده‌ها روی همان سیستم.

## اولویت قوانین چگونه کار می‌کند؟

کشیک‌یار دیگر «Hard» و «امتیاز» را دو گزینه جدا نمی‌داند. هر قانون یک مقدار واحد از ۰ تا ۱۰۰ دارد. مقدار ۱۰۰ همان Hard یا خط قرمز است.

مثال:

- روز ممنوع = ۱۰۰ → فرد در آن روز نباید کشیک باشد.
- جفت = ۷۵ → الگوریتم تلاش زیادی برای کنار هم قرار دادن جفت می‌کند.
- جفت نشدن = ۲۵ → بهتر است رعایت شود، اما در شرایط سخت قابل نقض است.
- مورنینگ = ۵۰ → عدالت مورنینگ با اهمیت متوسط در چیدمان اثر می‌گذارد.

ابتدا وزن‌های کلی برای همه افراد تعیین می‌شوند. هر فرد به‌طور پیش‌فرض از همین مقادیر استفاده می‌کند و فقط در صورت نیاز می‌توان برای همان فرد مقدار متفاوتی تعریف کرد.

## شروع سریع

1. فایل `sample_people.xlsx` را باز کنید و ساختار نمونه را ببینید.
2. در برنامه وارد بخش «ورود از Excel» شوید.
3. فایل را انتخاب و Mapping ستون‌ها را کنترل کنید.
4. اسامی و محدودیت‌های هر فرد را بررسی کنید.
5. بخش‌ها و ظرفیت پیش‌فرض را تعیین کنید.
6. ماه، تعطیلات، روزهای دارای احتمال مورنینگ و ظرفیت روزهای خاص را تنظیم کنید.
7. در صفحه «چیدمان» اولویت کلی قوانین را مشخص کنید.
8. تعداد تلاش الگوریتم را انتخاب و چیدمان را اجرا کنید.
9. بخش «تحلیل» را بررسی کنید و در پایان Excel خروجی بگیرید.

## ورود از Excel

ردیف اول عنوان ستون‌ها و هر ردیف بعدی یک فرد است. ترتیب ستون‌ها اجباری نیست، چون بعد از ورود فایل Mapping انجام می‌شود.

ستون‌های نمونه:

| ستون | محتوا |
|---|---|
| A | نام |
| B | تعداد کشیک |
| C | تعداد کشیک تعطیل |
| D | اجازه ۴۸ی |
| E | روزهای ممنوع |
| F | روزهای ترجیحی |
| G | جفت با |
| H | نباشد با |
| I | مورنینگ ماه‌های قبل |
| J | شیفت‌های مجاز |
| K | حداکثر روز متوالی |
| L | کشیک ماه‌های قبل |
| M | کشیک تعطیل ماه‌های قبل |
| N تا R | اولویت شخصی پنج قانون؛ خالی = استفاده از تنظیم کلی |

## اجرا در Windows

روی `START_KESHIK.bat` دوبار کلیک کنید. فایل اجرا ابتدا Chrome یا Edge را جست‌وجو می‌کند و در صورت پیدا نشدن، از مرورگر پیش‌فرض Windows استفاده می‌کند.

برای تجربه مطمئن‌تر، Windows 10/11 و مرورگر به‌روز توصیه می‌شود.

## حریم داده

اطلاعات اسامی، محدودیت‌ها و کشیک در LocalStorage مرورگر همان کامپیوتر ذخیره می‌شوند. خود Solver، تحلیل و تولید برنامه برای کارکرد عادی به هیچ API یا سرویس هوش مصنوعی متصل نیستند.

فقط قابلیت دریافت آنلاین تعطیلات به اینترنت نیاز دارد و تعریف دستی تقویم همیشه در دسترس است.

## ساختار پروژه

- `index.html` — رابط کاربری
- `styles.css` — استایل‌ها
- `app.js` — مدیریت UI، Excel، تقویم و داده‌ها
- `solver.js` — موتور چیدمان و امتیازدهی
- `jalali.js` — محاسبات تقویم جلالی
- `holidays.js` — داده تقویم داخلی نمونه
- `xlsx-lite.js` — ورود و خروج Excel در مرورگر
- `sample_people.xlsx` — فایل نمونه و راهنمای Import
- `START_KESHIK.bat` — اجرای ساده روی Windows

## پیشنهاد برای مشارکت

Issue باز کنید اگر:

- باگ یا رفتار غیرمنتظره مشاهده کردید.
- یک قانون کشیک جدید پیشنهاد دارید.
